WISHPORT — EXPLORER / CART UX UPDATE (2026-11-11)

WishPort is an independently branded ACNH item explorer and Discord order command builder, with mobile-friendly browsing and a redesigned shopping cart.

Features: Database, Collections, Categories, Villagers; searchable ACNH catalog; expanded category / suggested-theme / suggested-series / type / variation-color filters; show/hide variation labels; page size (25/50/100), first/last/page jumping; one-tap item adding; full stack counts; requested item cards with +/- and remove; villager selection; 40 slots; filler choices (default, NMT, crowns, Bells); hexadecimal $order codes; protected DIY metadata and special-event-item exclusions.

IMPORTANT: Not all WishPort item IDs, color metadata, or DIY cards have been verified with your running SysBot. The color and thematic selectors are browsing aids; a 4-digit item code does NOT guarantee a selected color, and some variations require longer codes. Keep SysBot RequireValidInventoryMetadata enabled. Test before sharing.
